We built a simple and, or, xor gates

This project demonstrates the behavior of three fundamental logic gates and how they are used in basic digital circuit design.

Project Description

In this project, we designed and tested simple AND, OR, and XOR gate circuits. The goal was to understand how different input combinations produce different outputs and to build a clear foundation in digital logic.

Tools: Breadboard / simulator, logic ICs, LEDs

Focus: Truth tables, gate behavior, and circuit testing
