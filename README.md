# Teymur Huseynov — Personal Portfolio Website

A responsive personal portfolio website built with HTML, CSS, and JavaScript, hosted on GitHub Pages.

## Live Website

[https://skxdixc.github.io](https://skxdixc.github.io)

## Design Inspiration

Inspired by [brittanychiang.com](https://brittanychiang.com) — a dark-themed developer portfolio with a clean layout, modern look, and smooth structure. I liked the style and wanted to create something similar with my own personal touch.

## Pages

- **Home** — Introduction, profile photo, contact links
- **About** — Background, goals, and skills
- **Projects** — Three projects with descriptions and photos
- **Game** — Bonus Snake game built in JavaScript

## Projects

- **Project 1** — Logic Gates: Built simple AND, OR, XOR gate circuits on a breadboard
- **Project 2** — School AI Workshop: Visited a local school and taught students coding and AI basics
- **Project 3** — Lego Robot: Built and programmed a Lego robot to draw a square shape

## Features

- Dark navy theme with cyan accents
- Responsive design (works on mobile and desktop)
- Light/Dark mode toggle
- Navigation bar and footer on every page
- Links to GitHub and Codecademy profiles
- Bonus interactive Snake game
