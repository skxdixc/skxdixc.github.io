Project 3

We built a Lego robot and programmed it to move in a square path and draw a square shape.

Project Description

This project focused on robotics, teamwork, and programming logic. We assembled a Lego robot, calibrated its movement, and wrote a control sequence for precise turns and equal side lengths. By combining motion and timing correctly, the robot was able to draw a square shape on the surface.

Main Topics: Robotics, sequencing, motion control

Goal: Use coding to control real-world robot movement
